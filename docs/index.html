Install the Mac app

  1. Unzip Subtitle-QC-Player.zip

    Double-click it in your Downloads folder.

  2. Move Subtitle QC Player to Applications.
  3. Allow it the first time

    The app isn't signed with an Apple Developer ID, so macOS blocks it on the first launch with a message that it "could not verify" the app. Click Done.

    Then open System Settings › Privacy & Security, scroll to the Security section and click Open Anyway next to Subtitle QC Player. On a work Mac this may need an administrator's password.

    After that it opens normally. Replacing it with a newer version may ask once more.

What it does

  • Checks a subtitles folder (TTML, IMSC, iTT, DFXP, WebVTT, SRT, SCC) against the language code list: labelled, expected and detected language, Full / Forced / SDH, cue checks.
  • Matches each subtitle file to its episode video by file name.
  • QC player with a waveform bar, subtitle events, and timecode from the video's own timecode track.
  • J / K / L shuttle, frame stepping with ← →, and ↑ ↓ to jump between subtitle events.
Reads the folders you choose and never changes your files. Works offline.
