Video analysis in Chrome: feasibility test

Reads a video straight from a folder you pick (nothing is uploaded), decodes single frames and times every step, then estimates how long the planned analysis of a 45-minute episode would take in Chrome. H.264 / HEVC: Chrome's own decoder (WebCodecs). ProRes: a small ProRes-only decoder built from FFmpeg (). For a network drive, pick a folder on it.
