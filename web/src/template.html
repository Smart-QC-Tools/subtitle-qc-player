Help

Keyboard

  • SpacePlay / pause (always back to normal speed)
  • KPause
  • ← →Back / forward one frame
  • Shift+← →Jump 5 seconds
  • ⌥ Option+← →Jump 5 minutes
  • ↑ ↓Previous / next subtitle event (follows the filter, search and the table's sort order)
  • LPlay; press again for 2× → 4× → 6×. From reverse, one step back towards normal play
  • JReverse at 2×; press again for 4× → 6×. While playing forward, one step slower (1× → ◀◀ 2×). Reverse has no sound
  • Ctrl/⌘+scrollZoom the waveform bar
  • Shift+scrollMove along the waveform bar

Waveform bar

  • Press or drag on the bar to move the playhead. Click a subtitle block to select that event in the table.
  • The handle underneath shows the visible part of the video: drag it to move, drag its ends to zoom between 5 seconds and the whole video.
  • The channel menu picks which audio channels are drawn. It doesn't change what you hear.

Offset & timing

  • The offset is the timecode of the video's first frame. It's filled in automatically when the video has a timecode track; otherwise type the burned-in start timecode (hh:mm:ss:ff). ± flips the sign.
  • A typed offset is remembered for that video.
  • Timecodes in the player and the table count from 00:00:00:00 at the first frame of the video.
  • The frame rates of the video and the subtitle file are shown beside the volume. A difference is marked (except SCC, which is always 29.97).

Colours

  • Red breaks a rule: over the line-length (CPL) limit, more lines than allowed, overlap, too short or too long on screen, odd (invisible / control) characters.
  • Amber worth a look: reading speed over the CPS limit, lines of one event aligned differently, unusual placement (raised, or left / right-aligned), a 1-frame gap to the next event (the subtitle blinks off for a frame; back-to-back events with no gap are fine).
  • Grey placed at the top.

Event table

  • In / Out turn red where events overlap; Out turns amber before a 1-frame gap. Duration is seconds:frames (2:13s), or minutes:seconds:frames from a minute up (1:05:12m).
  • Pos (placement) is blank for the usual bottom-centre. L / R: left / right-aligned · Mix: lines aligned differently (amber) · Raised · Top. A very short event with a long line has its duration in a stronger red.
  • Click a row to jump there; click a column heading to sort (again to reverse). Hover a row for the characters on each line and every flag in words.
  • Under the player: the selected event (or the one playing) in detail, with the characters on each line.

Limits, filters, search

  • Lines, CPS and CPL limits are set above the table and apply everywhere, including the Conform page. CPS counts every character, spaces included, over the time on screen.
  • Filters show only the events with that flag; click the active one again to show everything. Only checks that found something get a button; the rest are listed as clean underneath.
  • All issues shows every event with a red or amber flag (placement and top are not included).
  • Search is not case-sensitive. Paste an odd character to find more of it.
  • Translate (Chrome 138+) puts an English translation under the events in view, using Chrome's on-device translator.

Folders & files

  • Select the videos folder and the subtitles folder at the top (or drop them on the window). Next time they come back by themselves in the Mac app, or with one click (Reopen) in the browser.
  • Subtitle formats: TTML, IMSC, iTT, DFXP, WebVTT, SRT and SCC. Videos: whatever the player can play (ProRes and more in the Mac app).
  • Audio-only files, dubcards and clips under a minute are set aside under “Ignored” in the videos list.

What's checked

  • Label: the language code inside the file, checked against the reference language list (Expected).
  • Detected: the language the text is actually in, and any other languages found in it.
  • Checks: anything else worth knowing, such as the file name saying a different language, a season / episode that doesn't match the video or the folder, or encoding damage (“�” or garbled characters like “Ã©”).
  • Per-event checks (reading speed, line length, overlaps …) are on the QC tab.
  • Click a row for details; ▶ opens the file in the player.

Grouping & matching

  • Group by the language in the file names, or by episode. The language buttons show one language at a time; All shows everything.
  • Subtitle files are matched to videos by production code, season / episode or episode title. “Matched only” hides files without a match, on both tabs.
  • In the player, switching episodes keeps the same language when there is one; switching subtitle files keeps the playback position.

Subtitle QC Player

  • Everything runs on this computer; no file or subtitle is uploaded anywhere.
  • Problems are written to a log file: Help ▸ Show Log File in the menu bar. Sending it along helps when something goes wrong.
  • The Mac app plays more video formats (ProRes and others) and keeps its settings between sessions on its own.
